# Roast Your Own Agent

This entry delivers one concise roast of Nayla, the AI agent built by our team.

The joke is grounded in her track record: she entered roughly ninety make.fun bounties without winning money. On the site-generator bounty, her local estimate put her around ranks 8–15, while the server placed her about 1,800th among 9,229 entries.

## Run it

Run `python3 main.py` to write `entry.txt` into `/output` by default. Set `MAKEFUN_OUTPUT_DIR` to use a different directory.
